# Walkcraft para Android

[Descargar la APK más reciente](https://github.com/JMosh89/Walkcraft-Descargas/releases/latest)

## Instalar y actualizar

1. Descarga el archivo terminado en `.apk` de la versión publicada.
2. Ábrelo en Android y confirma la instalación sobre Walkcraft.
3. Conserva la aplicación instalada para mantener tu partida; actualiza sin desinstalarla.

La versión 0.7.8 incorpora el comprobador de actualizaciones. Si tienes una versión anterior, instala esta APK una vez manualmente. A partir de ella, el juego podrá avisarte cuando publiquemos una versión nueva; pulsa **Actualizar** para abrir la descarga y confirma después la instalación en Android.

Los avisos requieren conexión a Internet y se muestran cuando no hay un combate o una ventana abierta. La versión 0.7.8 no se ofrece a sí misma: el primer aviso llegará con una versión posterior.
